2.1 - المتغيّرات (Variables)

ما هو المتغيّر؟

المتغيّر (Variable) هو خلية ذاكرة نخزن فيها قيمة. لكل متغيّر اسم نستخدمه للوصول إلى القيمة وتغييرها. الفكرة الأولى في الشرائح هي برنامج يقرأ درجات حرارة الصباح والظهر والمساء، يحسب المتوسط ثم يطبعه.

نحتاج متغيّرات لحفظ القيم التي سيستعملها البرنامج لاحقًا.
قبل استعمال متغيّر في Java يجب تعريفه وتحديد نوعه.

الأعداد الصحيحة - int

النوع int يخزن أعدادًا صحيحة مثل 20 أو -7. لا يمكن وضع 16.5 داخل int لأن 16.5 عدد حقيقي يحتوي جزءًا عشريًا.

int mTemp = 20;
int nTemp = 34;
int eTemp = 18;
int average = (mTemp + nTemp + eTemp) / 3;

الأعداد الحقيقية - double

النوع double يخزن أعدادًا حقيقية مثل 16.5 و 24.0. في Java تظهر قيمة double مع نقطة عشرية حتى لو كانت قيمتها الرياضية عددًا صحيحًا.

double mTemp = 20;
double nTemp = 34;
double eTemp = 16.5;
double average = (mTemp + nTemp + eTemp) / 3;

أنواع الأعداد التي تظهر في المادة

مجموعةالأنواع
أعداد صحيحةbyte, short, int, long
أعداد حقيقيةfloat, double

المادة تذكر أن int هو النوع الافتراضي الشائع للأعداد الصحيحة وdouble هو النوع الأساسي الذي سنستعمله للأعداد الحقيقية في هذا المستوى.

تعريف المتغيّر وإسناد قيمة

int a1;
short s2 = 15, s3 = 10, s4;
double d1, d2, d3 = 12.557;
التعريف يحدد النوع والاسم.
يمكن إسناد قيمة أثناء التعريف أو لاحقًا.
يمكن تعريف أكثر من متغيّر من النوع نفسه في السطر نفسه، لكن للطلاب المبتدئين أحيانًا يكون تعريف كل متغيّر في سطر مستقل أوضح.

قواعد تسمية المتغيّرات

لا نستخدم كلمة محجوزة في Java مثل int أو public كاسم متغيّر.
يمكن استعمال الأحرف الإنجليزية والأرقام و _ و $، لكن الاسم لا يبدأ برقم.
لا يمكن تعريف متغيّرين بالاسم نفسه داخل النطاق نفسه.
المتبع هو camelCase: نبدأ بحرف صغير، وكل كلمة إضافية تبدأ بحرف كبير، مثل finalGrade.
اختر اسمًا يوضح معنى القيمة، لا اسمًا عشوائيًا.

الطباعة: نص وقيمة متغيّر

النص داخل علامات الاقتباس يُطبع كما هو، أما اسم المتغيّر خارج علامات الاقتباس فيُستبدل بقيمته.

System.out.print("The average temp = ");
System.out.println(average);

ويمكن دمجهما في أمر واحد باستخدام +:

System.out.println("The average temp = " + average);
قاعدة للامتحان: إذا كتبت "average" داخل علامات الاقتباس ستُطبع كلمة average، وليس قيمة المتغيّر average.

تمرين الفصل - مساحة شبه منحرف

الشرائح تعطي شبه منحرف متساوي الساقين أبعاده مرتبطة بالمتغيّر x: القاعدة القصيرة x، والقاعدة الطويلة 2.5x، والارتفاع 1.25x. المطلوب تعريف المتغيّرات، حساب المساحة، ثم طباعة النتيجة.

double x = 8.2;
double base1 = x;
double base2 = 2.5 * x;
double height = 1.25 * x;
double area = (base1 + base2) * height / 2;
System.out.println("Area = " + area);
ملاحظة: هذا حل تعليمي واضح يحافظ على فكرة التمرين. يمكن أيضًا كتابة الحساب بتعبير واحد، لكن فصل القيم يساعد الطالب على الفهم.

تمرين الفصل - علامة نهائية موزونة

التقييم المدرسي 30% وعلامة الامتحان التجريبي 25%، وكلاهما في الشرائح على مقياس 0..10، بينما علامة الامتحان 45% وعلى مقياس 0..100. لذلك يجب تحويل أول علامتين إلى مقياس 0..100 قبل تطبيق النسب.

int teacher = 9;
int preExam = 8;
int examGrade = 85;

double finalGrade = teacher * 10 * 0.30
                  + preExam * 10 * 0.25
                  + examGrade * 0.45;
System.out.println("The final grade = " + finalGrade);

للقيم 9، 8، 85 تكون النتيجة 85.25 كما في الشريحة.

2.2 - العمليات الحسابية (Arithmetic Operations)

عملية الإسناد Assignment

في البرمجة x = 5 تعني: احسب القيمة الموجودة على اليمين ثم خزّنها في المتغيّر الموجود على اليسار. لذلك 5 = x غير صحيح في Java لأن الطرف الأيسر يجب أن يكون مكانًا يمكن التخزين فيه.

int x;
x = 5;
int a = x;
x = 8;

بعد int a = x يحصل a على نسخة من قيمة x في تلك اللحظة. تغيير x بعد ذلك لا يغيّر a.

الجمع والطرح والضرب والقسمة

double d1 = 2.0, d2 = 5.0;
double sum = d1 + d2 + 6.0;
double sub = d1 - d2;
double mul = 2 * d1 * d2;
double div = d2 / d1;

عندما تكون القيم double، تكون النتيجة double مثل 13.0 أو 2.5.

القسمة بين أعداد صحيحة

إذا كان الطرفان int، فالقسمة صحيحة وتُحذف الخانة العشرية. لذلك 5 / 2 يعطي 2 وليس 2.5.

التعبيرالنتيجةالنوع
12 / 43int
12 / 52int
12 / 4.03.0double
12.0 / 52.4double
قاعدة للامتحان: وجود متغيّر double على يسار الإسناد لا يصلح حسابًا سبق أن نُفذ كقسمة int. نوع العملية يحدد أثناء الحساب على اليمين.

أكثر من عامل في التعبير

نطبق أولوية العمليات الحسابية، وعندما تكون العمليات في الدرجة نفسها ننفذ من اليسار إلى اليمين.

التعبيرالنتيجة

11 / 4 * 2.04.0
11 / 4.0 * 25.5
11.0 / 4 * 25.5
11 - 6 / 28
4 * 5.0 - 11 / 418.0

باقي القسمة - مودولو %

عند قسمة عددين صحيحين يمكن التفكير في خارج القسمة والباقي. العامل % يعيد الباقي.

11 / 4   // 2
11 % 4   // 3
17 / 3   // 5
17 % 3   // 2

لعددين صحيحين a و b: الباقي يساوي a - (a / b) * b.

كتابة مختصرة لتحديث متغيّر

++ و --

a++ أو ++a يزيدان a بمقدار 1، وa-- أو --a ينقصانه بمقدار 1. الفرق يظهر عندما تكون الزيادة جزءًا من تعبير أكبر.

int a = 5;
int b = a++;  // b gets 5, then a becomes 6

int x = 5;
int y = ++x;  // x becomes 6, then y gets 6
قاعدة للامتحان: إذا كان ++ أو -- في سطر مستقل، لا فرق عمليًا بين الشكل القبلي والبعدي. الفرق مهم عندما تشارك العملية في إسناد أو تعبير.

تمرين الفصل - من دقائق إلى ساعة

إذا مر x دقيقة منذ منتصف الليل، نستعمل القسمة الصحيحة لاستخراج الساعات و% لاستخراج الدقائق.

int x = 1000;
int hour24 = (x / 60) % 24;
int minute = x % 60;
System.out.println(hour24 + ":" + minute);

int hour12 = hour24 % 12;
System.out.println(hour12 + ":" + minute);

للـ 1000 دقيقة النتيجة في دورة 24 ساعة هي 16:40، وفي دورة 12 ساعة 4:40.

تمرين إضافي من الشرائح - من ثوانٍ إلى h:m:s

int x = 55105;
int hour = (x / 3600) % 24;
int minute = (x / 60) % 60;
int second = x % 60;
System.out.println(hour + ":" + minute + ":" + second);

2.3 - تحويل الأنواع (Casting)

لماذا نحتاج Casting؟

إذا كانت درجات الحرارة int مثل 20، 35، 18 فإن التعبير (20 + 35 + 18) / 3 يُحسب كقسمة صحيحة ويعطي 24، رغم أن المتوسط الحقيقي 24.333... تغيير نوع المتغيّر average إلى double وحده لا يكفي، لأن القسمة نفسها حدثت قبل الإسناد.

ملاحظة: في الصفحة 6 من ملف 2.3 توجد زلة مطبعية في الكسر المرسوم: يظهر 20+34+18 مع نتيجة 24.3333، بينما الكود في نفس الصفحة يستعمل nTemp = 35. الحساب المتسق مع الكود هو (20+35+18)/3 = 24.3333...

طرق جعل القسمة حقيقية

double a1 = (mTemp + nTemp + eTemp) / 3.0;
double a2 = 1.0 * (mTemp + nTemp + eTemp) / 3;
double a3 = (double)(mTemp + nTemp + eTemp) / 3;
double a4 = (mTemp + nTemp + eTemp) / (double)3;

في كل صيغة صحيحة يجب أن يشارك double في القسمة قبل ضياع الجزء العشري.

صيغة Casting

(double)a1
(int)(d1 * a2 / d3)
(int)2.3333

التحويل يغيّر النوع محليًا ومؤقتًا لأجل التعبير، ولا يغيّر بالضرورة نوع المتغيّر الأصلي.

مكان التحويل مهم

double good = ((double)mTemp + nTemp + eTemp) / 3;
double bad  = (double)((mTemp + nTemp + eTemp) / 3);

في bad حدثت القسمة الصحيحة أولًا، ثم حوّلنا 24 إلى 24.0؛ الجزء العشري ضاع بالفعل.

التحويل التلقائي

Java تسمح عادةً بتحويل نوع أصغر/أضيق إلى نوع أوسع عندما لا يوجد خطر فقدان معلومات، مثل int إلى double. أما double إلى int فقد يفقد الجزء العشري، لذلك يحتاج تحويلًا صريحًا.

double d = 20;       // automatic conversion: 20 -> 20.0
int x = (int)16.5;   // explicit conversion: 16

هرمية الأنواع العددية في المادة

الشرائح تعرض تسلسلًا تعليميًا من الأنواع الأصغر إلى الأوسع تقريبًا: byte → short → int → long → float → double. التحويل باتجاه الأوسع غالبًا تلقائي، والعودة إلى نوع أضيق تحتاج Casting صريحًا لأنها قد تفقد معلومات.

double إلى int لا يعني تقريبًا

التعبيرالنتيجة
(int)12.912
(int)12.112
(int)-12.9-12
(int)-12.1-12
قاعدة للامتحان: Casting إلى int يحذف الجزء العشري باتجاه الصفر؛ لا يطبّق تقريبًا رياضيًا.

تمرين الفصل - قص النتيجة إلى خانتين عشريتين

الفكرة: نحرك النقطة خانتين يمينًا، نحذف الجزء العشري بواسطة (int)، ثم نعيدها خانتين يسارًا.

double d = 2.33333;
double twoDigits = (int)(d * 100) / 100.0;
// 2.33

تحدي الشرائح - تقريب موجب إلى خانتين

للقيم الموجبة، تضيف الشرائح فكرة 0.5 قبل التحويل إلى int حتى يتم تقريب الجزء إلى أقرب عدد صحيح بعد تحريك النقطة.

double d = 10.0 / 6.0;
double rounded = (int)(d * 100 + 0.5) / 100.0;
// 1.67
ملاحظة: هذا التحدي في المادة محدد للأعداد الموجبة في هذه المرحلة، لذلك لا نعممه على السالب دون تعلم قواعد إضافية.

2.4 - إدخال البيانات من المستخدم (Scanner)

لماذا الإدخال أثناء التشغيل؟

بدل تعديل الكود وإعادة ترجمته لكل درجات حرارة جديدة، نجعل البرنامج يطلب القيم من المستخدم أثناء التشغيل.

إنشاء Scanner

import java.util.Scanner;

Scanner scan = new Scanner(System.in);

import يكتب في أعلى الملف قبل تعريف الفئة. scan هو اسم الكائن ويمكن اختيار اسم آخر.

استدعاء عملية على الكائن

int mTemp = scan.nextInt();
double price = scan.nextDouble();
قاعدة للامتحان: انتبه إلى اتجاه العرض: الصحيح هو scan.nextInt() و scan.nextDouble() من اليسار إلى اليمين، وليس nextInt.scan.

إدخال عدة قيم متتالية

يمكن لـ Scanner قراءة القيم إذا فصل المستخدم بينها بمسافة أو Enter أو Tab بحسب العملية. لذلك يمكن طلب ثلاث درجات حرارة ثم استدعاء nextInt ثلاث مرات.

System.out.println("Enter temperatures for morning, noon & evening");
int mTemp = scan.nextInt();
int nTemp = scan.nextInt();
int eTemp = scan.nextInt();

InputMismatchException

nextInt() يتوقع تمثيل عدد صحيح. إذا أدخل المستخدم 25.6 أو نصًا مثل abc، تفشل محاولة تحويل الإدخال إلى int ويحدث خطأ وقت تشغيل من نوع InputMismatchException.

java.util.InputMismatchException
هذه ليست Compilation Error؛ البرنامج تُرجم ثم فشل أثناء التشغيل بسبب نوع إدخال غير مناسب.
nextDouble() مخصصة للأعداد الحقيقية، وهناك عمليات مشابهة للأنواع الأخرى مثل nextFloat وnextLong وغيرها.

تمرين الفصل - تحسين برنامج شبه المنحرف

بدل قيمة x ثابتة، نقرأ القاعدتين والارتفاع من المستخدم بواسطة nextDouble ثم نحسب المساحة.

Scanner scan = new Scanner(System.in);
System.out.println("Enter base1, base2 and height");
double base1 = scan.nextDouble();
double base2 = scan.nextDouble();
double height = scan.nextDouble();
double area = (base1 + base2) * height / 2;
System.out.println("Area = " + area);

تمرين الفصل - السعر بعد الخصم

Scanner scan = new Scanner(System.in);
System.out.println("Enter original price and discount percent");
double price = scan.nextDouble();
int discount = scan.nextInt();
double newPrice = price * (100 - discount) / 100.0;
System.out.println("New price = " + newPrice);
قاعدة للامتحان: إذا كان discount من نوع int، استعمال 100.0 أو تحويل مناسب يمنع الوقوع في قسمة صحيحة عندما يكون التعبير يحتاج قيمة حقيقية.

2.5 - التحكم في سير البرنامج: if و else

ما هو الشرط؟

الشرط سؤال جوابه true أو false. if ينفذ أمرًا أو مجموعة أوامر فقط عندما يكون التعبير المنطقي true.

if (avg > 25) {
    System.out.println("It was a warm day");
}
يجب أن نحسب avg قبل فحصه.
إذا الشرط false نتجاوز جسم if ونكمل بعده.

التعبير المنطقي وعوامل المقارنة

العاملالمعنى
>أكبر من
>=أكبر من أو يساوي
<أصغر من
<=أصغر من أو يساوي
==يساوي
!=لا يساوي
قاعدة للامتحان: لا تخلط بين = للإسناد و == للمقارنة.

else - الحالة المعاكسة

if (avg > 25) {
    System.out.println("It was a warm day");
} else {
    System.out.println("It was a regular day");
}

مع if/else ينفذ واحد فقط من الفرعين.

الأقواس والمسافة البادئة

الشرائح تذكر أن الأقواس ليست إلزامية إذا كان هناك أمر واحد فقط، لكن يُنصح بالكتابة مع الأقواس والمسافة البادئة لأنها أوضح وأقل عرضة للأخطاء.

تمرين الفصل - الأكبر والأصغر من عددين

int max, min;
if (a > b) {
    max = a;
    min = b;
} else {
    max = b;
    min = a;
}
System.out.println("max = " + max);
System.out.println("min = " + min);

2.6 - الشروط المتداخلة والعوامل المنطقية AND / OR / NOT

الشرط المتداخل (Nested Condition)

الشرط المتداخل هو if موجود داخل جسم if آخر. الشرائح تبني مثال يوم شديد الحرارة: المتوسط أكبر من 25، وفقط إذا تحقق ذلك نفحص هل حرارة الظهر على الأقل 35.

if (avg > 25) {
    if (nTemp >= 35) {
        System.out.println("It was a very hot day");
    } else {
        System.out.println("It was a regular day");
    }
} else {
    System.out.println("It was a regular day");
}

تمرين الرقم: هل القيمة خانة واحدة؟

الرقم الواحد (digit) في التمرين هو عدد بين 0 و9. يمكن فحصه بشرط متداخل، أو لاحقًا بشرط AND واحد.

if (num >= 0) {
    if (num < 10) {
        System.out.println("is digit");
    }
}

AND - العامل &&

AND يكون true فقط عندما يكون الشرطان true.

if (avg > 25 && nTemp >= 35)

if (num >= 0 && num < 10) {

Short Circuit في AND

يُفحص التعبير من اليسار إلى اليمين. إذا كان الشرط الأول في && يساوي false، فالنتيجة كلها false ولا حاجة لتقييم الشرط الثاني.

تمرين العدد ذو خانتين

if (num >= 10 && num < 100) {
    System.out.println("2 digits");
}

قاعدة ارتباط else

إذا لم تكن الأقواس واضحة، else ترتبط بأقرب if سابقة غير مرتبطة بـ else. هذه قاعدة مهمة جدًا في أمثلة الشرائح التي تقارن مقطعي كود متشابهين بمسافات مختلفة.

قاعدة للامتحان: لا تعتمد على المسافات فقط لمعرفة لأي if تتبع else؛ اعتمد على الأقواس وبنية الكود. الأفضل كتابة الأقواس دائمًا.

OR - العامل ||

OR يكون true إذا كان شرط واحد على الأقل true. مثال الشرائح: يوم مناسب للنزهة إذا كانت حرارة الصباح أقل من 20 أو المتوسط أقل من 25.

if (mTemp < 20 || avg < 25)

truefalsetrue
falsetruetrue

Short Circuit في OR

إذا كان الشرط الأول في || يساوي true، فالنتيجة كلها true ولا حاجة لتقييم الشرط الثاني.

تمرين: ليس عددًا ذا خانتين

إذا كان العدد غير ذي خانتين، فهو أصغر من 10 أو أكبر من أو يساوي 100.

if (num < 10 || num >= 100) {
    System.out.println(true);
}

NOT - العامل !

! يعكس قيمة التعبير المنطقي: true تصبح false، وfalse تصبح true.

قاعدة للامتحان: عند نفي تعبير مركب، الأقواس مهمة جدًا: !(A || B) تنفي النتيجة كلها.

2.7 - if / else if و switch

اختيار واحد من عدة إمكانيات

عندما لدينا عدة نطاقات أو حالات، يمكن ترتيبها باستخدام if ثم else if. أول شرط true يُنفذ، وما بعده في السلسلة لا يُفحص.

if (avg >= 20 && avg <= 22) {
    System.out.println("very cold day");
} else if (avg == 23 || avg == 24) {
    System.out.println("cold day");
} else if (avg == 25) {
    System.out.println("nice day");
} else if (avg == 26 || avg == 27) {
    System.out.println("warm day");
} else if (avg >= 28 && avg <= 30) {
    System.out.println("very warm day");
} else {
    System.out.println("avg is out of range");
}

لماذا else if أوضح من if متداخلة كثيرة؟

الشرائح تبدأ بكتابة if داخل else ثم تحسن الشكل تدريجيًا إلى else if. المعنى واحد، لكن الشكل النهائي أقصر وأسهل للقراءة عندما الخيارات متبادلة.

switch - اختيار حسب قيم محددة

switch مناسب عندما نفحص قيمة واحدة مقابل قيم محددة مسبقًا. case تستقبل قيمة محددة، لا شرطًا منطقيًا مثل avg >= 20 && avg <= 22.

switch (avg) {
    case 20:
    case 21:
    case 22:
        System.out.println("very cold day");
        break;
    case 23:
    case 24:
        System.out.println("cold day");
        break;
    case 25:
        System.out.println("nice day");
        break;
    default:
        System.out.println("avg is out of range");
}

دور break في switch

بدون break، بعد العثور على case المطابقة يستمر التنفيذ إلى الحالات التالية (fall-through) حتى يصل إلى break أو نهاية switch. الشرائح تعرض هذا الخطأ صراحةً عندما تظهر عدة طباعات متتالية.

قاعدة للامتحان: في هذا المستوى: بعد أوامر كل حالة مستقلة في switch، افحص هل تحتاج break. نسيانها من الأخطاء الشائعة.

البنية العامة لـ switch

switch (expression) {
    case value1:
        // statements
        break;
    case value2:
        // statements
        break;
    default:
        // statements for all other values
}

تمرين الفصل - رقم الشهر واسمه

المستخدم يدخل رقم شهر، والبرنامج يطبع اسمه بالإنجليزية. switch مناسب لأن لدينا 12 قيمة محددة.

switch (month) {
    case 1:  System.out.println("January"); break;
    case 2:  System.out.println("February"); break;
    case 3:  System.out.println("March"); break;
    // ... continue through 12
    default: System.out.println("Invalid month");
}

تمرين متابعة - فصل السنة

الشرائح تطلب إضافة تقرير عن الفصل: Autumn للأشهر 9..11، Winter للأشهر 12,1,2، Spring للأشهر 3..5، وSummer للأشهر 6..8. يمكن إضافة if/else if بعد الجزء الأول أو استعمال switch منظّم.

2.8 - الرموز (char) والسلاسل النصية (String)

إدخال كلمة بواسطة next()

next() تقرأ سلسلة حتى أول محرف أبيض: مسافة أو Tab أو Enter. لذلك هي مناسبة للاسم الأول أو كلمة واحدة.

String name = scan.next();

إدخال سطر كامل بواسطة nextLine()

nextLine() تقرأ حتى Enter، ولذلك يمكنها قراءة اسم كامل مكوّن من عدة كلمات.

String fullName = scan.nextLine();
قاعدة للامتحان: الاستدعاء الصحيح يُعرض دائمًا LTR: scan.next(), scan.nextInt(), scan.nextDouble(), scan.nextLine().

لماذا فشل إدخال اسم كامل مع next()?

إذا كتب المستخدم David Cohen، فإن next() تستهلك David فقط وتترك Cohen في الإدخال. إذا كان الاستدعاء التالي nextInt() فسوف يحاول تحويل Cohen إلى int ويحدث InputMismatchException.

char - رمز واحد

char نوع بدائي يخزن رمزًا واحدًا، ونكتبه بين اقتباسين مفردين.

char ch = 'a';

String - سلسلة نصية

String ليست نوعًا بدائيًا؛ هي فئة، والمتغيّر يشير إلى كائن String. يمكن مع ذلك إنشاء String مباشرة بطريقة مريحة:

String str1 = "abcd123";

مقارنة String بواسطة equals

لأن String كائن، المادة تعلم أن مقارنة المحتوى تتم بواسطة equals وليس ==.

if (str1.equals(str2)) {
    System.out.println("same text");
}
قاعدة للامتحان: يجب أن يظهر التعبير من اليسار إلى اليمين: str1.equals(str2)، وليس equals.str1.

دمج Strings بواسطة +

String s1 = "abc" + 5;       // "abc5"
String s2 = "abc" + 5 + 5;   // "abc55"
String s3 = "abc" + 'a';     // "abca"
String s4 = "abc" + (5 + 5); // "abc10"

عند وجود String، يتحول + إلى دمج نصي. الأقواس قد تغير ما يُحسب أولًا.

تمرين الفصل - تسجيل الدخول بثلاث محاولات

البرنامج يخزن كلمة مرور، يسمح حتى ثلاث محاولات، وينهي المحاولات عند النجاح. الشرائح تعرض تنظيمين: شروط متداخلة، أو استعمال متغيّر boolean مثل success.

String password = "abcde";
boolean success = false;

System.out.println("Enter password");
String guess = scan.next();
if (guess.equals(password)) {
    success = true;
} else {
    System.out.println("Try again");
    guess = scan.next();
    if (guess.equals(password)) {
        success = true;
    } else {
        System.out.println("Try again");
        guess = scan.next();
        if (guess.equals(password)) {
            success = true;
        }
    }
}

if (success) {
    System.out.println("Login successful");
} else {
    System.out.println("Account locked");
}
ملاحظة: الفصل 2 لم يقدم الحلقات بعد، لذلك تمرين المحاولات الثلاث مكتوب بشروط متداخلة/متغير boolean وليس بحلقة. الحلقات تأتي في فصل لاحق.
