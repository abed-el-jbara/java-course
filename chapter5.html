5.1 - حلقة while (كلما / طالما أن الشرط صحيح)

لماذا نحتاج إلى حلقة؟

الحلقة (Loop) هي طريقة لتنفيذ مجموعة من الأوامر أكثر من مرة. الأوامر التي تتكرر تسمّى جسم الحلقة (Loop Body)، والاختبار الذي يقرر هل نكرر مرة أخرى يسمى شرط الحلقة (Loop Condition).

نستخدم while عندما لا نعرف مسبقًا عدد مرات التكرار، مثل لعبة التخمين التي تستمر حتى ينجح المستخدم.
كل تنفيذ كامل لجسم الحلقة يسمى تكرارًا واحدًا (Iteration).

مثال اللعبة: من ثلاث محاولات إلى عدد محاولات غير معروف

في المثال الأول كانت عملية check(secret) تُستدعى عدة مرات يدويًا. الفكرة الأفضل هي: نفّذ التخمين، وإذا فشل، أعد التخمين طالما أن النتيجة false.

boolean res = check(secret);
while (res == false) {
    res = check(secret);
}
System.out.println("Game over. Number is: " + secret);
قاعدة للامتحان: في while يجب أن تسأل نفسك دائمًا: ما الذي قد يغيّر قيمة شرط الحلقة؟ إذا لم يتغيّر شيء مرتبط بالشرط فقد نحصل على حلقة لا نهائية.

البنية العامة لحلقة while

while (booleanExpression) {
    // commands
}
قبل كل تكرار يتم فحص الشرط.
إذا كان الشرط true ينفذ جسم الحلقة.
إذا كان الشرط false تنتهي الحلقة ويستمر البرنامج من أول أمر بعدها.
إذا كان في الجسم أمر واحد فقط يمكن حذف الأقواس المعقوفة، لكن في هذا الدليل نفضّل إبقاءها لتقليل الأخطاء.

نمط مهم: قراءة حتى قيمة إنهاء

عندما لا نعرف عدد القيم التي سيدخلها المستخدم، يمكن اختيار قيمة خاصة لإنهاء الإدخال. في أمثلة الفصل استُخدمت -1.

Scanner scan = new Scanner(System.in);
int sum = 0;
int num;
System.out.println("Enter Expenses, -1 to finish");
num = scan.nextInt();
while (num != -1) {
    sum += num;
    num = scan.nextInt();
}
System.out.println("Sum is: " + sum);
قاعدة للامتحان: لماذا نقرأ أول قيمة قبل الحلقة؟ لأن الشرط يحتاج قيمة يفحصها قبل الدخول إلى أول تكرار. ثم نقرأ قيمة جديدة في نهاية كل تكرار.

حساب متوسط عدد غير معروف من العلامات

لحساب المتوسط نحتاج شيئين: مجموع العلامات وعدد العلامات. بعد انتهاء الإدخال نحسب المجموع ÷ العدد.

Scanner scan = new Scanner(System.in);
double sum = 0;
int noGrades = 0;
int num;
System.out.println("Enter Grades, -1 to finish");
num = scan.nextInt();
while (num != -1) {
    sum += num;
    noGrades++;
    num = scan.nextInt();
}
if (noGrades == 0) {
    System.out.println("No Grades");
} else {
    System.out.println("Average = " + sum / noGrades);
}
يجب معالجة الحالة التي لم يُدخل فيها المستخدم أي علامة، وإلا نحاول القسمة على 0.
يجب أن يكون الحساب عشريًا (double) حتى لا نخسر الجزء العشري من المتوسط.

تفكيك عدد: استخراج الأرقام واحدًا واحدًا

لعدد صحيح موجب، num % 10 يعطينا رقم الآحاد، و num / 10 يحذف رقم الآحاد.

int sum = 0;
while (num != 0) {
    sum += num % 10;
    num = num / 10;
}

مثال للعدد 3852: نضيف 2 ثم 5 ثم 8 ثم 3، وفي النهاية يصبح num مساويًا 0 ويكون المجموع 18.

قاعدة للامتحان: ترتيب الأوامر مهم. إذا حذفنا رقم الآحاد قبل أن نستخدمه فقد نفقده. لذلك غالبًا: استخرج/استخدم الرقم أولًا، ثم احذفه.

فحص هل كل أرقام العدد زوجية

public static boolean isEvenDigits(int num) {
    while (num != 0) {
        int digit = num % 10;
        if (digit % 2 != 0) {
            return false;
        }
        num = num / 10;
    }
    return true;
}

عند العثور على رقم فردي نعرف فورًا أن الجواب false، لذلك لا حاجة لمتابعة فحص بقية الأرقام.

ثلاث طرق لإيقاف العمل مبكرًا

return: ينهي العملية (Method) كلها ويعيد قيمة إن كانت العملية غير void.
break: ينهي الحلقة الحالية فقط، ثم يستمر التنفيذ بعد الحلقة.
تغيير شرط الحلقة: يمكن أن نجعل الشرط يحتوي أكثر من جزء، مثل num != 0 && res.
boolean res = true;
while (num != 0 && res) {
    int digit = num % 10;
    if (digit % 2 != 0) {
        res = false;
    }
    num = num / 10;
}
return res;

الأمر break

while (num != 0) {
    int digit = num % 10;
    if (digit % 2 != 0) {
        res = false;
        break;
    }
    num = num / 10;
}

عند تنفيذ break نخرج من الحلقة مباشرة، ثم ننتقل إلى أول أمر بعد الحلقة.

الأمر continue

continue ينهي التكرار الحالي فقط. في while ينتقل التنفيذ إلى فحص شرط الحلقة من جديد.

public static void printEven(int num) {
    while (num != 0) {
        int digit = num % 10;
        num = num / 10;
        if (digit % 2 != 0) {
            continue;
        }
        System.out.print(digit);
    }
}
قاعدة للامتحان: عند استخدام continue في while تأكد أن التغييرات التي تمنع الحلقة من أن تصبح لا نهائية حدثت قبل continue. في المثال نحذف رقم الآحاد قبل continue.

الحلقة اللانهائية (Infinite Loop)

الحلقة اللانهائية هي حلقة يبقى شرطها true ولا يحدث داخلها ما يجعل الشرط false أو يخرج منها بأمر مثل break أو return.

int i = 0;
while (i != 10) {
    i = i + 3;
}

هذه الحلقة لا تصل إلى 10: القيم تكون 0، 3، 6، 9، 12... ولذلك تستمر بلا نهاية.

int i = 20;
while (i < 10) {
    i = i + 2;
}

هذه ليست حلقة لا نهائية؛ الشرط false منذ البداية، لذلك جسم الحلقة لا ينفذ أصلًا.

تمرين فحص كود: لماذا قد لا تتوقف الحلقة؟

int num = scan.nextInt();
int sum = 0;
while (sum < 20) {
    sum = num;
}
System.out.println("Sum is: " + sum);

إذا كانت قيمة num أصغر من 20، يصبح sum مساويًا لها في كل تكرار ويبقى أصغر من 20، لذلك لا تتوقف الحلقة. كذلك لا توجد قراءة جديدة داخل الحلقة، وكتابة sum = num لا تجمع الأعداد.

while (num != 0) {
    num = num % 2;
}

هذه الحلقة قد تصبح لا نهائية عندما يصبح num مساويًا 1، لأن 1 % 2 يساوي 1 في كل مرة. أما إذا أصبحت القيمة 0 فتنتهي الحلقة.

نطاق تعريف المتغيّرات (Scope)

int i = 0;
while (i < 10) {
    int num = i;
    i = i + 2;
}
// num is not known here

المتغيّر الذي نعرّفه داخل جسم الحلقة معروف فقط داخل هذا الجسم. لا يمكن استخدام num بعد القوس الذي يغلق الحلقة.

تمرين الفصل: العدد الأولي

العدد الأولي (Prime Number) هو عدد صحيح أكبر من 1 لا يقبل القسمة إلا على 1 وعلى نفسه. المطلوب في المادة كتابة العملية:

public static boolean isPrime(int num)

فكرة الحل: جرّب قواسم ممكنة ابتداءً من 2، وإذا وجدت قاسمًا يعيد باقي القسمة 0 فالعدد غير أولي.

public static boolean isPrime(int num) {
    if (num <= 1) {
        return false;
    }
    int i = 2;
    while (i < num) {
        if (num % i == 0) {
            return false;
        }
        i++;
    }
    return true;
}

5.2 - حلقة for

متى نفضّل for؟

عندما يكون عدد التكرارات معروفًا مسبقًا، تكون حلقة for غالبًا أوضح. مثال: قراءة 20 علامة أو طباعة الأعداد من 0 إلى 9.

int sum = 0;
for (int i = 0; i < 20; i++) {
    System.out.println("Enter grade");
    int num = scan.nextInt();
    sum += num;
}
System.out.println("Avg is: " + sum / 20.0);

بنية حلقة for

for (initialization; condition; update) {
    // body commands
}
التهيئة (Initialization): تنفذ مرة واحدة فقط قبل أول فحص للشرط.
الشرط (Condition): يفحص قبل كل تكرار.
التحديث / التقدّم (Update): ينفذ بعد نهاية كل تكرار، ثم يعود البرنامج لفحص الشرط.
مثال شائع: for (int i = 0; i < 20; i++).

ترتيب التنفيذ بدقة

الخطوةما يحدث
1التهيئة
2فحص الشرط
3إذا true: تنفيذ جسم الحلقة
4تنفيذ التحديث
5العودة إلى فحص الشرط
6إذا false: الخروج من الحلقة

تتبّع مثال لثلاث علامات

int sum = 0;
for (int i = 0; i < 3; i++) {
    int num = scan.nextInt();
    sum += num;
}
System.out.println(sum / 3.0);

إذا كانت القيم 90، 80، 100 يصبح المجموع 270 والمتوسط 90.0.

ملاحظة: ملاحظة على الشرائح: في مثال تتبّع ثلاث علامات ظهر في أحد مقاطع الكود القسمة على 20.0، لكن المثال نفسه والنتيجة 90.0 يوضحان أن المقصود هنا 3.0. في هذا الدليل استخدمنا الصيغة الصحيحة للمثال.

أمثلة على التحديث

for (int i = 0; i <= 9; i++) {
    if (i % 2 == 0) {
        System.out.print(i + " ");
    }
}
// 0 2 4 6 8

يمكن تقليل عدد التكرارات إذا كان المطلوب فقط الأعداد الزوجية، وذلك بجعل عداد الحلقة يقفز بمقدار 2:

for (int i = 0; i <= 9; i = i + 2) {
    System.out.print(i + " ");
}
// 0 2 4 6 8
for (int i = 0; i <= 12; i = i + 3) {
    System.out.print(i + " ");
}
// 0 3 6 9 12
for (int i = 9; i >= 0; i--) {
    System.out.print(i + " ");
}
// 9 8 7 6 5 4 3 2 1 0

عدد كامل / تام (Perfect Number)

العدد الكامل هو عدد يساوي مجموع قواسمه الموجبة دون احتساب العدد نفسه. مثال: 6 قواسمه 1، 2، 3 ومجموعها 6.

public static boolean isPerfect(int num) {
    int sum = 0;
    for (int i = 1; i < num; i++) {
        if (num % i == 0) {
            sum += i;
        }
    }
    return sum == num;
}

حقول فارغة في for

يمكن ترك أي حقل من حقول for فارغًا. عندما يكون حقل فارغًا تتخطى الحلقة هذه المرحلة.

for ( ; num != 0; ) {
    sum += num % 10;
    num = num / 10;
}

إذا تُرك الشرط فارغًا فالقيمة الافتراضية له true، ولذلك for(;;) حلقة لا نهائية ما لم نخرج منها مثلًا بـ break أو return.

for ( ; ; ) {
    sum += num % 10;
    num = num / 10;
    if (num == 0) {
        break;
    }
}

break و continue داخل for

break في for مثل while: ينهي الحلقة الحالية. أما continue في for فينهي التكرار الحالي ثم ينتقل إلى مرحلة التحديث، وبعدها يُفحص الشرط.

public static void printSplit(int num) {
    for (int i = 1; i <= num; i++) {
        if (num % i != 0) {
            continue;
        }
        System.out.print(i + " ");
    }
}

نطاق متغيّرات for

for (int i = 0; i < 10; i++) {
    // i is known here
}
// i is not known here

إذا عرّفنا المتغيّر في جزء التهيئة داخل for فهو لا يكون معروفًا بعد انتهاء الحلقة.

أكثر من أمر في التهيئة أو التحديث

يمكن كتابة أكثر من أمر في التهيئة أو في التحديث، ونفصل بينها بفاصلة.

for (int i = 1, num = 1; i < n; i++, num = i * i) {
    System.out.println(i + "^2 = " + num);
}

التحويل بين while و for

الفكرة نفسها يمكن غالبًا كتابتها بأي من الحلقتين. المهم نقل التهيئة والشرط والتحديث إلى الأماكن الصحيحة.

// while
int res = 1;
while (y > 0) {
    res = res * x;
    y--;
}

// equivalent for
int res2 = 1;
for ( ; y > 0; y--) {
    res2 = res2 * x;
}

تمارين إضافية على التحويل بين while و for

في عملية mod نطرح y من x ما دام x أكبر من أو يساوي y. يمكن نقل التحديث إلى جزء update في for:

public static int mod(int x, int y) {
    for ( ; x >= y; x -= y) {
        // no body command is needed
    }
    return x;
}

وفي عملية عكس أرقام عدد، يمكن تحويل for إلى while مع إبقاء حذف رقم الآحاد كتحديث داخل جسم الحلقة:

public static int rev(int num) {
    int res = 0;
    while (num > 0) {
        res = res * 10 + num % 10;
        num = num / 10;
    }
    return res;
}
// factorial with for
public static int factorial(int num) {
    int res = 1;
    for (int i = 1; i <= num; i++) {
        res = res * i;
    }
    return res;
}
ملاحظة: ملاحظة على الشرائح: ظهر في مثال factorial الحرف I الكبير في شرط الحلقة. المتغيّر المعرّف هو i الصغير، لذلك الصيغة الصحيحة هي i <= num.

تمرين: طباعة جميع الأعداد الأولية حتى max

public static void printPrimes(int max) {
    for (int i = 2; i <= max; i++) {
        if (isPrime(i)) {
            System.out.print(i + " ");
        }
    }
}

هذا التمرين يربط بين حلقة for واستدعاء عملية أخرى: لكل عدد من 2 حتى max نستعمل isPrime لتحديد هل نطبعه.

5.3 - الحلقات، الرموز (char) والسلاسل النصية (String)

ما هو char؟

الرمز (char / Character) هو قيمة تمثل رمزًا واحدًا: حرفًا، رقمًا مكتوبًا كرمز، علامة ترقيم، أو رمز تحكم. في Java نكتب char بين علامتي اقتباس مفردتين مثل A أو 7 عندما نعرضهما كرموز في الكود.

char newLine = '\n';
char tab = '\t';
char letter = 'A';
char digit = '7';
الرقم 7 من النوع int يختلف عن الرمز '7' من النوع char.
كل char له قيمة رقمية في جدول ترميز. في هذا الفصل نستخدم جدول ASCII.

جدول ASCII - القيم التي يجب فهمها

المجموعةالمجال في ASCII
الأرقام 0..9من 48 إلى 57
الحروف الإنجليزية الكبيرة A..Zمن 65 إلى 90
الحروف الإنجليزية الصغيرة a..zمن 97 إلى 122

سبب أهمية الترتيب: الأحرف والأرقام متتالية، لذلك نستطيع المقارنة بينها وإجراء عمليات حسابية عليها.

'A' == 65
'a' + 3   // reaches 'd' conceptually
'a' < 'e' // true

التحويل بين char و int (Casting)

(char) 102   // 'f'
(int) '^'    // 94

التحويل (Casting) يسمح بالانتقال بين القيمة الرقمية للرمز والرمز نفسه.

تأكد من فهم قيم ASCII

من أمثلة الشرائح: عند زيادة الرمز K بمقدار واحد نحصل على L. والتحويل من القيمة 102 إلى char يعطي الرمز f، وتحويل الرمز ^ إلى int يعطي القيمة 94.

char ch = 'K';
ch++;          // 'L'
(char)102      // 'f'
(int)'^'       // 94

التعرّف على مجموعات من الرموز

// lowercase letter
'a' <= ch && ch <= 'z'

// uppercase letter
'A' <= ch && ch <= 'Z'

// digit character
'0' <= ch && ch <= '9'
public static boolean isSmallLetter(char ch) {
    return 'a' <= ch && ch <= 'z';
}

public static boolean isLetter(char ch) {
    return ('a' <= ch && ch <= 'z') ||
           ('A' <= ch && ch <= 'Z');
}

public static int digit2int(char ch) {
    return ch - '0';
}

التحويل بين حرف صغير وحرف كبير

char ch = 'd';
ch = (char)(ch - 'a' + 'A');
// ch becomes 'D'

للاتجاه المعاكس، أي من حرف كبير إلى حرف صغير، نستخدم الفكرة نفسها:

ch = (char)(ch - 'A' + 'a');

حلقة تمر على الحروف من a إلى z

public static void ascii_a2z() {
    for (char ch = 'a'; ch <= 'z'; ch++) {
        System.out.println(ch + "	" + (int)ch);
    }
}

String كسلسلة من الرموز

السلسلة النصية (String) هي تسلسل من الرموز. للوصول إلى عدد الرموز نستخدم length()، وللحصول على رمز في موقع معيّن نستخدم charAt(index).

String s = "abc";
s.length();    // 3
s.charAt(0);   // 'a'
s.charAt(2);   // 'c'
قاعدة للامتحان: فهرسة String تبدأ من 0. آخر مؤشر صالح يساوي طول السلسلة ناقص 1.
str.length() - 1

فحص قوة كلمة مرور

بحسب تمرين الفصل، كلمة المرور القوية يجب أن تحتوي على 8 رموز على الأقل، وحرف كبير واحد على الأقل، ورقم واحد على الأقل.

public static boolean isStrongPw(String pw) {
    if (pw.length() < 8) {
        return false;
    }
    boolean hasCapital = false;
    boolean hasDigit = false;

    for (int i = 0; i < pw.length(); i++) {
        char ch = pw.charAt(i);
        if ('A' <= ch && ch <= 'Z') {
            hasCapital = true;
        }
        if ('0' <= ch && ch <= '9') {
            hasDigit = true;
        }
    }
    return hasCapital && hasDigit;
}

سلسلة متناظرة (Palindrome)

السلسلة المتناظرة تُقرأ بالشكل نفسه من اليمين إلى اليسار ومن اليسار إلى اليمين، مثل aba و 12321.

نقارن أول رمز بآخر رمز، ثم الثاني بما قبل الأخير، ونستمر حتى يلتقي المؤشران.

public static boolean isPalindrome(String str) {
    int left = 0;
    int right = str.length() - 1;

    while (left < right) {
        if (str.charAt(left) != str.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

عكس سلسلة نصية

public static String reverse(String str) {
    String word = "";
    for (int i = str.length() - 1; i >= 0; i--) {
        word = word + str.charAt(i);
    }
    return word;
}

إذا كانت السلسلة هي abc، فإن التنفيذ يبني النتيجة على المراحل: c ثم cb ثم cba.

شفرة قيصر (Caesar Cipher)

في شفرة قيصر نستبدل كل حرف بحرف يبعد عنه عددًا ثابتًا من المواقع. إذا تجاوزنا z أو Z نعود إلى بداية الأبجدية.

في مثال الشرائح، LUCK بإزاحة 10 تصبح VEMU عند التعامل مع الأحرف الكبيرة. في العملية المعروضة للتشفير يتم تطبيق الفكرة على الأحرف الصغيرة a..z، وأي رمز آخر ينسخ كما هو.

public static String encryption(String msg, int k) {
    String message = "";
    for (int i = 0; i < msg.length(); i++) {
        char ch = msg.charAt(i);
        if ('a' <= ch && ch <= 'z') {
            ch += k;
            if ('z' < ch) {
                ch -= 26;
            }
        }
        message += ch;
    }
    return message;
}
ملاحظة: هذه الصيغة هي صيغة الفصل وتفترض إزاحة مناسبة بحيث يكفي الرجوع 26 مرة واحدة. في أسئلة هذا الفصل اتبعوا حدود السؤال والكود الذي تم تدريسه.

فك شفرة قيصر

public static String decrypt(String msg, int k) {
    String result = "";
    for (int i = 0; i < msg.length(); i++) {
        char ch = msg.charAt(i);
        if ('a' <= ch && ch <= 'z') {
            ch -= k;
            if (ch < 'a') {
                ch += 26;
            }
        }
        result += ch;
    }
    return result;
}

في مثال المادة، عند فك السلسلة vemu بإزاحة 10 تكون النتيجة luck.

5.4 - الحلقة المتداخلة (Nested Loop)

الفكرة الأساسية

الحلقة المتداخلة هي حلقة داخل حلقة أخرى. الحلقة التي تحتوي غيرها تسمى الحلقة الخارجية (Outer Loop)، والحلقة الموجودة بداخلها تسمى الحلقة الداخلية (Inner Loop).

قاعدة للامتحان: في كل تكرار واحد للحلقة الخارجية، تُنفّذ الحلقة الداخلية كاملة من بدايتها إلى نهايتها.

مثال: جدول الضرب

لطباعة 12 صفًا و8 أعمدة: الحلقة الخارجية تختار الصف، والحلقة الداخلية تمر على أعمدة ذلك الصف.

for (int line = 1; line <= 12; line++) {
    for (int i = 1; i <= 8; i++) {
        System.out.print(line * i + "	");
    }
    System.out.println();
}

طباعة مستطيل من النجوم

public static void printRectangle(int m, int n) {
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            System.out.print("* ");
        }
        System.out.println();
    }
}

الخارجية تتكرر m مرات = عدد الصفوف، والداخلية تتكرر n مرات في كل صف = عدد الأعمدة.

طباعة مثلث قائم من النجوم

public static void printTriangular(int n) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            System.out.print("* ");
        }
        System.out.println();
    }
}

الفرق عن المستطيل أن عدد تكرارات الحلقة الداخلية يتغير حسب رقم الصف i: الصف الأول نجمة واحدة، الثاني نجمتان، وهكذا.

قراءة مخرجات حلقات متداخلة

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 5; j++) {
        System.out.print("* ");
    }
    System.out.println();
}

الناتج: 3 صفوف، وفي كل صف 5 نجوم.

for (int i = 1; i <= 5; i++) {
    for (int j = 5; j >= i; j--) {
        System.out.print("*");
    }
    System.out.println();
}

عدد النجوم يقل في كل صف: 5 ثم 4 ثم 3 ثم 2 ثم 1.

for (int i = 1; i <= 3; i++) {
    for (int k = 1; k <= 5; k++) {
        System.out.print(i);
    }
    System.out.println();
}

الناتج: 11111 ثم 22222 ثم 33333، كل مجموعة في صف جديد.

int i = 1;
while (i < 10) {
    for (int j = 1; j <= 5; j++) {
        System.out.print("^");
    }
    System.out.println();
    i = i * 2;
}

قيم i هي 1، 2، 4، 8؛ لذلك تُطبع أربعة صفوف، كل صف يحتوي 5 رموز ^. هذا مثال على دمج while خارجية مع for داخلية.

تمرين جمع التبرعات

خمس فئات / صفوف دراسية. لكل فئة ندخل مبالغ الطلاب حتى -1، ثم ننتقل للفئة التالية. في النهاية نريد مجموع كل فئة، المجموع العام، ورقم الفئة ذات أكبر مجموع.

Scanner scan = new Scanner(System.in);
int totalAll = 0;
int maxClass = 0;
int maxSum = -1;

for (int cls = 1; cls <= 5; cls++) {
    int classSum = 0;
    int amount = scan.nextInt();

    while (amount != -1) {
        classSum += amount;
        amount = scan.nextInt();
    }

    System.out.println("Class " + cls + ": " + classSum);
    totalAll += classSum;

    if (classSum > maxSum) {
        maxSum = classSum;
        maxClass = cls;
    }
}
System.out.println("Total = " + totalAll);
System.out.println("Max class = " + maxClass + ", sum = " + maxSum);
ملاحظة: الحل أعلاه حل مقترح مبني على متطلبات التمرين في الشرائح. الفكرة الأساسية التي يجب فهمها هي for خارجية للفئات و while داخلية لعدد طلاب غير معروف في كل فئة.

5.5 - تدريبات شاملة على الحلقات

تمرين 01 - أكبر رقم داخل عدد

اكتبوا عملية تستقبل عددًا صحيحًا وتعيد أكبر رقم فيه. للعدد 17234 تعاد القيمة 7، وللعدد 128348 تعاد القيمة 8، وللعدد -3245 تعاد القيمة 5. المطلوب التدرّب على while و for.

public static int maxDigit(int num) {
    if (num < 0) {
        num = -num;
    }
    int max = 0;
    while (num != 0) {
        int digit = num % 10;
        if (digit > max) {
            max = digit;
        }
        num = num / 10;
    }
    return max;
}

تمرين 02 أ - خمن العدد

البرنامج يختار عددًا بين 1 و100. بعد كل تخمين يخبر المستخدم إن كان التخمين أكبر أو أصغر، وينتهي فقط عند النجاح.

Random rnd = new Random();
int secret = rnd.nextInt(100) + 1;
int guess = scan.nextInt();
while (guess != secret) {
    if (guess > secret) {
        System.out.println("Too high. Enter a number");
    } else {
        System.out.println("Too low. Enter a number");
    }
    guess = scan.nextInt();
}
System.out.println("Well done!");

تمرين 02 ب - خمن العدد مع حد أقصى للمحاولات

أضيفوا حدًا لعدد التخمينات، مثل 4 محاولات. تتوقف اللعبة عند النجاح أو عند استهلاك المحاولات.

int tries = 0;
boolean found = false;
while (tries < 4 && !found) {
    int guess = scan.nextInt();
    tries++;
    if (guess == secret) {
        found = true;
    } else if (guess > secret) {
        System.out.println("Too high.");
    } else {
        System.out.println("Too low.");
    }
}
if (found) {
    System.out.println("Well done!");
} else {
    System.out.println("Game Over. Number is: " + secret);
}

تمرين 03 - سلسلة 7 بوم

اطبعوا حتى 100 كل عدد يقبل القسمة على 7 أو يحتوي الرقم 7.

public static boolean hasDigit7(int num) {
    while (num != 0) {
        if (num % 10 == 7) {
            return true;
        }
        num = num / 10;
    }
    return false;
}

for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0 || hasDigit7(i)) {
        System.out.print(i + " ");
    }
}

تمرين 04 - اكتشاف أخطاء برنامج المتوسط

الأخطاء في الكود المعطى تشمل: sum لم يُهيأ، يعاد ضبط sum داخل الحلقة، قراءة القيمة الجديدة قبل إضافة القديمة، count يبدأ من 1، قيمة -1 قد تدخل في المجموع، والقسمة قد تكون صحيحة عددية.

Scanner scan = new Scanner(System.in);
int num = scan.nextInt();
double sum = 0;
int count = 0;
while (num != -1) {
    sum += num;
    count++;
    num = scan.nextInt();
}
if (count > 0) {
    double avg = sum / count;
    System.out.println("Average: " + avg);
}

تمرين 05 أ - عد الأعداد ذات الرقمين

المشكلة في الكود المعطى أنه يطبع count بدل أن يزيده. يجب تنفيذ count++ عند العثور على عدد بين 10 و99، ثم طباعة النتيجة بعد انتهاء الحلقة.

public static void count() {
    Scanner scan = new Scanner(System.in);
    int i = 0;
    int count = 0;
    while (i < 5) {
        int num = scan.nextInt();
        if (num <= 99 && num >= 10) {
            count++;
        }
        i++;
    }
    System.out.println("Count = " + count);
}

تمرين 05 ب - أخطاء إضافية في الإدخال

في نسخة، num يُستخدم قبل تعريفه.
في نسخة أخرى، num يُقرأ مرة واحدة فقط خارج الحلقة؛ لذلك نفس القيمة تُفحص خمس مرات.
القراءة يجب أن تحدث في كل تكرار، سواء كان العدد ذا رقمين أم لا.

تمرين 06 - مثلث متساوي الساقين من النجوم

المطلوب طباعة مثلث مقلوب، ثم كتحدٍ تحويله إلى مثلث قاعدته في الأسفل. نحتاج حلقة للمسافات وحلقة للنجوم في كل صف.

public static void printIsoTriangle(int lines) {
    for (int row = 0; row < lines; row++) {
        for (int s = 0; s < row; s++) {
            System.out.print(" ");
        }
        int stars = 2 * (lines - row) - 1;
        for (int j = 0; j < stars; j++) {
            System.out.print("*");
        }
        System.out.println();
    }
}

تمرين 07 - ساعة رملية من النجوم

العملية تستقبل maxStars، وهو في السؤال الأساسي موجب وفردي. النصف العلوي يقل بنجمتين في كل صف ثم النصف السفلي يزيد بنجمتين.

public static void hourglass(int maxStars) {
    for (int stars = maxStars; stars >= 1; stars -= 2) {
        int spaces = (maxStars - stars) / 2;
        for (int s = 0; s < spaces; s++) {
            System.out.print(" ");
        }
        for (int j = 0; j < stars; j++) {
            System.out.print("*");
        }
        System.out.println();
    }

    for (int stars = 3; stars <= maxStars; stars += 2) {
        int spaces = (maxStars - stars) / 2;
        for (int s = 0; s < spaces; s++) {
            System.out.print(" ");
        }
        for (int j = 0; j < stars; j++) {
            System.out.print("*");
        }
        System.out.println();
    }
}
ملاحظة: الحلان الخاصان بالمثلث والساعة الرملية هما حلول مقترحة للتدريب، لأن شرائح 5.5 تعرض صيغة السؤال والمخرجات المطلوبة دون حل كامل.

أخطاء شائعة جدًا في الامتحان

نسيان i++ أو تحديث المتغيّر في while، فتنتج حلقة لا نهائية.
استخدام <= بدل < أو العكس، فيحدث تكرار زائد أو ناقص.
البدء من 1 عندما يجب البدء من 0 عند العمل مع String.
استخدام str.length() كمؤشر أخير بدل str.length() - 1.
تحديث num قبل استخدام num % 10 عند تفكيك رقم.
وضع قراءة Scanner داخل if فتحدث القراءة فقط لبعض الحالات.
تعريف متغيّر داخل الحلقة ثم محاولة استعماله خارجها.
القسمة بين int عندما نحتاج double.
نسيان أن continue في for ينتقل إلى update، بينما في while يعود إلى فحص الشرط مباشرة.

اختبار ذاتي سريع

1. ما الفرق بين جسم الحلقة وشرط الحلقة؟ 2. متى نفضّل while ومتى for؟ 3. ما الفرق بين break و continue و return؟ 4. لماذا قد تصبح while حلقة لا نهائية؟ 5. ما آخر مؤشر صالح في String؟ 6. كيف نعرف أن char هو رقم؟ 7. ماذا يحدث للحلقة الداخلية في كل تكرار من الخارجية؟ 8. كيف نستخرج رقم الآحاد من عدد؟ 9. لماذا المتوسط قد يحتاج double؟ 10. ما معنى نطاق المتغيّر؟

إجابات مختصرة للاختبار الذاتي

1. الجسم هو الأوامر المتكررة والشرط يقرر هل نكرر. 2. while لعدد غير معروف غالبًا، وfor لعدد معروف غالبًا. 3. break يخرج من الحلقة، continue يتخطى بقية التكرار الحالي، return ينهي العملية. 4. إذا بقي الشرط true ولم يحدث تحديث أو خروج. 5. length()-1. 6. '0' <= ch && ch <= '9'. 7. تُنفّذ كاملة. 8. num % 10. 9. حتى لا نفقد الجزء العشري. 10. المكان الذي يكون فيه المتغيّر معروفًا ومسموحًا باستخدامه.

قاعدة للامتحان: عند حل سؤال تتبّع (Dry Run): اكتب جدولًا للمتغيّرات، وفحص الشرط، والقيمة المطبوعة بعد كل تكرار. لا تحاول حل كل شيء ذهنيًا مرة واحدة.
