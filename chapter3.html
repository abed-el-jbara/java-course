3.1 - استخدام العمليات الساكنة (Static Methods)

لماذا نحتاج عمليات جاهزة؟

سبق أن استخدمنا الأنواع الأساسية والعمليات الحسابية مثل الجمع والطرح والضرب والقسمة وباقي القسمة. لكن أحيانًا نحتاج عمليات أكثر تقدمًا، مثل الجذر التربيعي، القوة، القيمة المطلقة، الأصغر والأكبر، والتقريب.

في Java توجد فئات جاهزة / مدمجة (Built-in Classes) كتبها مطورو اللغة. تحتوي هذه الفئات على عمليات جاهزة موثقة في الـ API.

ما هو API؟

الـ API هو توثيق يشرح ما الذي تفعله الفئة والعملية، ما المعاملات التي تحتاجها، أنواعها وترتيبها، وما نوع القيمة المُعادة.

لا نحتاج أن نعرف كيف كُتبت العملية داخليًا حتى نستعملها.
يكفي أن نفهم عنوان العملية (Method Header) ووصفها والمعاملات والقيمة المُعادة.

الفئة Math

الفئة Math تحتوي عمليات رياضية جاهزة. العمليات التي ندرسها هنا ساكنة (static)، لذلك نستدعيها باسم الفئة ثم نقطة ثم اسم العملية.

ClassName.methodName(parameters)
double c = Math.sqrt(25.0);

القيمة المُعادة من Math.sqrt(25.0) هي 5.0، فتُوضَع مكان استدعاء العملية.

Math.sqrt - الجذر التربيعي

static double sqrt(double a)

تستقبل قيمة من النوع double وتعيد الجذر التربيعي الموجب كقيمة double.

double c = Math.sqrt(25.0);   // 5.0

يمكن تمرير 25 بدل 25.0 لأن Java تستطيع تحويل int إلى double في هذا السياق.

مثال: حساب وتر مثلث قائم الزاوية

بحسب فيثاغورس: c² = a² + b²، لذلك c = √(a² + b²).

Scanner scan = new Scanner(System.in);
System.out.println("Enter Triangle sides");
int a = scan.nextInt();
int b = scan.nextInt();

double c = Math.sqrt(a * a + b * b);
System.out.println("The Triangle side: " + c);

للقيم 3 و4 تكون النتيجة 5.0.

العملية Math.abs

static double abs(double a)

تعيد القيمة المطلقة. مثلًا Math.abs(-7) يعيد 7.

double x = Math.abs(-7);   // 7.0

العملية Math.min

public static int min(int a, int b)

تعيد الأصغر من قيمتين من النوع int.

int m = Math.min(8, 3);   // 3

العملية Math.max

تستخدم بالطريقة نفسها، لكنها تعيد القيمة الأكبر.

int m = Math.max(8, 3);   // 8

العملية Math.pow

static double pow(double a, double b)

ترفع المعامل الأول للقوة الموجودة في المعامل الثاني.

double d1 = Math.pow(2, 5);  // 32.0
double d2 = Math.pow(5, 2);  // 25.0
قاعدة للامتحان: ترتيب المعاملات مهم: Math.pow(2, 5) ليس مثل Math.pow(5, 2). اقرأ ترتيب المعاملات في الـ API.

الفرق بين دالة رياضية وعملية في برنامج

الدالة الرياضية عادةً تعمل على أعداد وتنتج عددًا. أما العملية في البرنامج فهي أكثر مرونة: قد تستقبل أنواعًا مختلفة من المعاملات أو لا تستقبل أي معامل، وقد تعيد قيمة من أنواع مختلفة أو لا تعيد قيمة إطلاقًا.

void println(String x)

println تستقبل String ولا تعيد قيمة، لذلك نوع القيمة المُعادة هو void.

Math.floor و Math.round

static double floor(double a)

Math.floor تعيد أكبر عدد صحيح رياضي أصغر من أو يساوي القيمة، لكن النتيجة من النوع double.

Math.floor(3.0)   // 3.0
Math.floor(3.123) // 3.0
Math.floor(3.999) // 3.0
static long round(double a)

Math.round تقرّب إلى أقرب عدد صحيح من النوع long. هذه ليست نفس فكرة floor.

تمرين الشرائح: هل العدد مربع كامل؟

العدد المربع الكامل هو عدد جذره التربيعي عدد صحيح، مثل 25 و36، بينما 29 ليس مربعًا كاملًا.

الخطوات في الشرائح: نحسب الجذر ثم نفحص هل الجذر يساوي Math.floor للجذر.

Scanner scan = new Scanner(System.in);
System.out.println("Enter number");
int num = scan.nextInt();

double n1 = Math.sqrt(num);

if (n1 == Math.floor(n1))
    System.out.println("Square Root");
else
    System.out.println("Not Square Root");
ملاحظة: في الشرائح طُرح أيضًا اقتراح استخدام Math.round بدل Math.floor. المقارنة مع round قد تعمل لاختبار أن قيمة موجبة محددة هي عدد صحيح عندما نقارن القيمة نفسها بنتيجة التقريب، لكن floor يعبّر بصورة مباشرة أكثر عن الفكرة التي استُخدمت في الحل المعروض.

3.2 - كتابة العمليات الساكنة (Writing Static Methods)

لماذا نكتب عملية بأنفسنا؟

عندما يتكرر جزء من الكود أو توجد مهمة واضحة يمكن فصلها، من الأفضل جمع الأوامر في عملية. هذا يقلل تكرار الكود، يجعل البرنامج أقصر وأسهل للقراءة والتعديل.

مثال الفصل: لعبة Bull and Cows

في اللعبة يختار البرنامج عددًا سريًا من رقمين مختلفين. المستخدم يخمّن عددًا من رقمين.

Bull: رقم صحيح وفي المكان الصحيح.
Cow: رقم موجود في العدد السري لكن في المكان الآخر.

مثال: السر 73 والتخمين 27 يعطي Cow واحدة بسبب الرقم 7. التخمين 74 يعطي Bull واحدة بسبب الرقم 7 في خانة العشرات.

كيف نستخرج رقم الآحاد والعشرات؟

int ones = num % 10;
int tens = num / 10;

لأن الأعداد في هذا المثال من رقمين فقط.

فحص Bulls

if (guess % 10 == secret % 10)
    bull++;

if (guess / 10 == secret / 10)
    bull++;

فحص Cows

if (guess % 10 == secret / 10)
    cows++;

if (guess / 10 == secret % 10)
    cows++;
ملاحظة: في صفحة 10 من الشرائح يظهر في النص العبري وصف النتيجة على أنها Bull في مثال المطابقة بمكان مختلف، بينما تعريف اللعبة والكود يوضحان أنها Cow. في الدليل نستخدم التعريف الصحيح المتوافق مع بقية الشرائح.

النسخة ذات محاولة واحدة

Scanner scan = new Scanner(System.in);
int secret = 73;
int bull = 0, cows = 0;

System.out.print("Enter 2 digits number ");
int guess = scan.nextInt();

if (guess % 10 == secret % 10)
    bull++;
if (guess / 10 == secret / 10)
    bull++;

if (guess % 10 == secret / 10)
    cows++;
if (guess / 10 == secret % 10)
    cows++;

if (bull == 2)
    System.out.println("Well done");
else
    System.out.println("Bull: " + bull + " Cows: " + cows);

مشكلة تكرار الكود

لإضافة ثلاث محاولات يمكن نسخ نفس جزء معالجة التخمين ثلاث مرات، لكن هذا يؤدي إلى تكرار الكود (Code Duplication): البرنامج يصبح طويلًا، أصعب للقراءة، وأي تغيير يجب تنفيذه في عدة أماكن.

تحويل الجزء المتكرر إلى عملية check

المهمة الواضحة هي معالجة تخمين واحد. العملية تحتاج العدد السري، لذلك سيكون secret مُعاملًا. نريد معرفة هل التخمين نجح، لذلك تعيد boolean.

public static boolean check(int secret)

كتابة العملية check

public static boolean check(int secret) {
    Scanner scan = new Scanner(System.in);
    int bull = 0, cows = 0;

    System.out.println("Enter 2 digits number");
    int guess = scan.nextInt();

    if (guess % 10 == secret % 10)
        bull++;
    if (guess / 10 == secret / 10)
        bull++;

    if (guess % 10 == secret / 10)
        cows++;
    if (guess / 10 == secret % 10)
        cows++;

    if (bull == 2) {
        System.out.println("Well done");
        return true;
    } else {
        System.out.println("Bull: " + bull + " Cows: " + cows);
        return false;
    }
}
قاعدة للامتحان: في عملية نوعها boolean يجب أن تعيد true أو false في كل مسار يصل إلى نهاية العملية.

استخدام check من main

public static void main(String[] args) {
    int secret = 73;

    if (check(secret) == false) {
        if (check(secret) == false) {
            check(secret);
        }
    }
}

عندما تكون العملية داخل الفئة نفسها يمكن استدعاؤها باسمها فقط، بدون كتابة اسم الفئة قبلها.

البنية العامة لعنوان عملية ساكنة

permissions static returnType name(type1 name1, type2 name2, ...)
public: من يستطيع استخدام العملية.
static: العملية لا تحتاج كائنًا معينًا.
returnType: نوع القيمة المُعادة.
name: اسم يدل على المهمة.
parameters: البيانات التي تحتاجها العملية.

الأمر return

return يعيد القيمة وينهي العملية فورًا. نوع القيمة بعد return يجب أن يلائم نوع القيمة المُعادة في عنوان العملية.

return true;
return sum;

تمرين ختامي 3.2 - مجموع أرقام عدد من ثلاثة أرقام

المطلوب قراءة عددين من ثلاثة أرقام وطباعة العدد الذي مجموع أرقامه أكبر. أولًا يظهر في الشرائح الحل بدون عملية، ثم يُستخرج الجزء المتكرر إلى عملية sumDigits.

public static int sumDigits(int num) {
    int sum = num % 10;
    sum += num / 10 % 10;
    sum += num / 100;
    return sum;
}
Scanner scan = new Scanner(System.in);
System.out.println("Enter 2 numbers with 3 digits");

int num1 = scan.nextInt();
int num2 = scan.nextInt();

int sum1 = sumDigits(num1);
int sum2 = sumDigits(num2);

int maxSum = num1;
if (sum1 < sum2)
    maxSum = num2;

System.out.println("max sum digits number = " + maxSum);

3.3 - استخدام عمليات الكائن (Object Methods)

الفرق بين عملية ساكنة وعملية كائن

العملية الساكنة يمكن استدعاؤها باسم الفئة، مثل Math.sqrt(...). أما العملية غير الساكنة فتحتاج كائنًا من الفئة، ثم نستدعي العملية على ذلك الكائن.

Math.sqrt(25)
rnd.nextInt(100)
قاعدة للامتحان: إذا حاولنا استدعاء عملية غير ساكنة مباشرةً على اسم الفئة، مثل Random.nextInt(), نحصل على خطأ ترجمة لأن العملية تحتاج كائنًا.

ما هو الكائن؟

الكائن (Object) هو مثيل (Instance) محدد من فئة. في هذا الفصل نتعلم استخدام الكائن؛ التفاصيل العميقة لبناء الفئات تأتي لاحقًا.

اسم متغير الكائن يعمل كمرجع / عنوان للكائن (Reference).

عملية البناء / الباني (Constructor)

لكل فئة عملية بناء / باني لإنشاء كائنات. اسم الباني يساوي اسم الفئة.

ClassName objectName = new ClassName(parameters);
Random rnd = new Random();

استيراد Random

import java.util.Random;

لأن Random ليست من الفئات المتاحة تلقائيًا بدون import في هذا السياق.

عمليات Random

int nextInt()

تعيد عدد int شبه عشوائي من مجال int.

int nextInt(int n)

تعيد عددًا من 0 شاملًا حتى n غير شامل.

Random rnd = new Random();

int a = rnd.nextInt();      // any int-range value
int b = rnd.nextInt(100);   // 0..99

كيف نبني مجالًا عشوائيًا مطلوبًا؟

للحصول على قيمة من 10 إلى 99 شاملًا نحتاج 90 قيمة. نولد 0..89 ثم نضيف 10.

int secret = 10 + rnd.nextInt(90);
أصغر قيمة: 0 + 10 = 10.
أكبر قيمة: 89 + 10 = 99.

منع رقمين متساويين في العدد السري

في لعبة Bull and Cows يجب أن يكون الرقمان مختلفين. الشرائح تقترح: إذا كان رقم العشرات يساوي رقم الآحاد، ننقص العدد 1.

if (secret / 10 == secret % 10) {
    secret--;
}

بهذا يصبح مثلًا 22 إلى 21، و33 إلى 32.

البرنامج الرئيسي بعد إضافة Random

Random rnd = new Random();

int secret = 10 + rnd.nextInt(90);

if (secret / 10 == secret % 10) {
    secret--;
}

if (check(secret) == false) {
    if (check(secret) == false) {
        check(secret);
    }
}

تمرين Random - رمي حجرَي نرد

كل حجر نرد يعطي قيمة من 1 إلى 6. لذلك نستخدم nextInt(6) + 1 مرتين.

Random rand = new Random();

int cube1 = rand.nextInt(6) + 1;
int cube2 = rand.nextInt(6) + 1;

System.out.println("Cubes: " + cube1 + ", " + cube2);

if (cube1 == cube2) {
    System.out.println("It's a Double");
}

تحدي الشرائح - حجران باستدعاء عشوائي واحد فقط

هناك 36 نتيجة مرتبة ممكنة لزوج من أحجار النرد. حل مقترح بسيط: نولد رقمًا واحدًا 0..35، ثم نحوله إلى نتيجتين.

int x = rand.nextInt(36);
int cube1 = x / 6 + 1;
int cube2 = x % 6 + 1;
ملاحظة: هذا حل مقترح للدليل مبني على التحدي في الشرائح؛ الشرائح تعرض السؤال والتلميح ولا تعرض في الصفحات المرفقة حلًا نهائيًا كاملًا.

String هو كائن

String يمثل سلسلة نصية وهو كائن من الفئة String. لذلك نستعمل عليه عمليات كائن مثل length(), substring(), replace(), charAt().

String str = scan.next();

الفهرس / مؤشر المكان (Index)

كل رمز في String له موقع يبدأ من 0. إذا كان طول السلسلة n فآخر فهرس صالح هو n - 1.

Stringcomputer
Index01234567
قاعدة للامتحان: الرمز الأول دائمًا عند الفهرس 0، والرمز الأخير عند str.length() - 1.

length() - طول السلسلة

int length()
String str = "computer";
int len = str.length();   // 8

substring(beginIndex)

String substring(int beginIndex)

تعيد سلسلة جزئية تبدأ من beginIndex شاملًا وتستمر حتى نهاية السلسلة.

"computer".substring(2)  // "mputer"
"computer".substring(4)  // "uter"

substring(beginIndex, endIndex)

String substring(int beginIndex, int endIndex)

تبدأ من beginIndex شاملًا، وتنتهي قبل endIndex؛ أي endIndex غير شامل.

"computer".substring(2, 6)  // "mput"
"computer".substring(0, 4)  // "comp"
قاعدة للامتحان: قاعدة مهمة جدًا: beginIndex شامل (inclusive)، وendIndex غير شامل (exclusive).

تقسيم كلمة إلى نصفين

في أمثلة الشرائح نفترض في البداية كلمة بطول زوجي.

int len = str.length();

String str1 = str.substring(0, len / 2);
String str2 = str.substring(len / 2);

str = str2 + str1;

computer تصبح utercomp، وaround تصبح undaro.

replace(oldChar, newChar)

String replace(char oldChar, char newChar)

تعيد String جديدًا بعد استبدال كل ظهور للرمز القديم بالرمز الجديد.

str = str.replace('o', '0');
str = str.replace('a', '@');

إذا لم يكن الرمز القديم موجودًا، تبقى السلسلة كما هي.

charAt(index)

char charAt(int index)

تعيد الرمز الموجود في فهرس معين.

String str = "computer";
char ch = str.charAt(3);   // 'p'

الحصول على أول وآخر رمز

char first = str.charAt(0);
char last = str.charAt(str.length() - 1);

برنامج إنشاء كلمة مرور - الخوارزمية الكاملة

الشرائح تبني كلمة مرور وفق أربع خطوات: نقل النصف الثاني إلى البداية، استبدال o بـ 0، استبدال a بـ @، ثم تبديل أول رمز وآخر رمز.

Scanner scan = new Scanner(System.in);
System.out.println("Enter a word");
String str = scan.next();

int len = str.length();

String str1 = str.substring(0, len / 2);
String str2 = str.substring(len / 2);
str = str2 + str1;

str = str.replace('o', '0');
str = str.replace('a', '@');

char c1 = str.charAt(0);
char c2 = str.charAt(len - 1);

str = str.substring(1, len - 1);
str = c2 + str + c1;

System.out.println("Suggested password: " + str);

computer تتحول إلى pterc0mu، وaround تتحول إلى 0nd@ru.

تمرين 01 - تحويل إنشاء كلمة المرور إلى عملية

العملية تستقبل String وتعيد String. اسم مقترح في الشرائح: suggestPswd.

public static String suggestPswd(String str) {
    int len = str.length();

    String str1 = str.substring(0, len / 2);
    String str2 = str.substring(len / 2);
    str = str2 + str1;

    str = str.replace('o', '0');
    str = str.replace('a', '@');

    char c1 = str.charAt(0);
    char c2 = str.charAt(len - 1);

    str = str.substring(1, len - 1);
    return c2 + str + c1;
}

تمرين 02 - استرجاع الكلمة الأصلية

الشرائح تطلب عملية تستقبل كلمة المرور وتحاول إرجاع الكلمة الأصلية. الصورة تستخدم اسمًا قريبًا من pswd2org.

لإلغاء الخطوات نعكسها بالترتيب: نعيد أول/آخر رمز، نعيد @ إلى a و0 إلى o، ثم نعيد نصفي الكلمة إلى ترتيبهما الأصلي.

مشكلة مهمة في الكلمات ذات الطول الفردي

في الصفحة 55 يظهر أن around تعمل، لكن peace لا تُسترجع بشكل صحيح. السبب الأساسي هو أن طول peace فردي. عند الإنشاء، len/2 يعطي 2، فيكون الجزء الأول بطول 2 والثاني بطول 3. بعد نقل الثاني إلى البداية، لا يجوز عند الاسترجاع تقسيم السلسلة مرة أخرى إلى 2 و3 بالطريقة نفسها.

قاعدة للامتحان: لعكس نقل النصفين عند طول فردي، يجب معرفة أن الجزء الذي نُقل إلى البداية طوله len - len/2، أي ceil(len/2).

حل تعليمي مقترح لاسترجاع ترتيب النصفين

int len = str.length();
int secondPartLength = len - len / 2;

String movedSecondPart = str.substring(0, secondPartLength);
String movedFirstPart = str.substring(secondPartLength);

str = movedFirstPart + movedSecondPart;
ملاحظة: هناك قيد إضافي منطقي: إذا كانت الكلمة الأصلية نفسها تحتوي 0 أو @، فلن يكون الاستبدال 0→o و@→a قابلاً للعكس بشكل مؤكد. هذا استنتاج من قواعد التحويل؛ الشرائح تركز في مثال الصفحة 55 على مشكلة الطول الفردي.

تمرين 03 - قائمة اختيار للمستخدم

المستخدم يختار 1 للحصول على كلمة مرور، أو 2 لمحاولة استرجاع الكلمة الأصلية. الفكرة تجمع بين العمليات الساكنة وعمليات String التي تعلمناها.

ملخص استخدام عمليات الكائن

إذا كانت الفئة تحتاج import نكتبه في أعلى الملف.
ننشئ كائنًا بواسطة الباني: ClassName objectName = new ClassName(...).
اسم متغير الكائن هو مرجع / عنوان للكائن.

نستخدم الـ API لفهم المعاملات والقيمة المُعادة وحدود كل عملية.

قواعد يجب حفظها للامتحان

اقرأ عنوان العملية: النوع المُعاد، الاسم، أنواع المعاملات وترتيبها.
استدعاء static يكون عادةً باسم الفئة؛ عملية الكائن تحتاج كائنًا.
return ينهي العملية ويعيد قيمة من النوع الصحيح.
الفهرسة في String تبدأ من 0.
آخر فهرس في String هو length() - 1.
substring(begin, end): البداية مشمولة والنهاية غير مشمولة.
nextInt(n) يعطي 0..n-1.
لتحريك مجال عشوائي نغير عرض المجال ثم نضيف قيمة البداية.
لا تكرر كودًا طويلًا إذا كانت له مهمة واضحة؛ حوّله إلى عملية.

أخطاء شائعة يجب تجنبها

استدعاء عملية كائن كما لو كانت عملية ساكنة، مثل Random.nextInt() بدل إنشاء كائن ثم استعمال rnd.nextInt().
نسيان كتابة اسم الفئة عند استدعاء عملية ساكنة من فئة أخرى، مثل كتابة sqrt(25) بدل Math.sqrt(25).
إرسال المعاملات بترتيب خاطئ، خصوصًا في Math.pow(a, b) و substring(beginIndex, endIndex).
نسيان أن نوع القيمة المُعادة يجب أن يطابق نوع المتغيّر الذي يستقبلها، أو نوع القيمة بعد return.
كتابة عملية من نوع boolean دون إرجاع true أو false في جميع المسارات الممكنة.
تكرار نفس مجموعة الأوامر في عدة أماكن بدل جمعها في عملية واضحة عندما تكون المهمة نفسها تتكرر.
نسيان أن nextInt(n) يولد من 0 شاملًا حتى n غير شامل؛ لذلك يجب تعديل المجال إذا أردنا مثلًا 1..6 أو 10..99.
الخلط بين الفهرس والطول: أول فهرس هو 0، وآخر فهرس صالح هو length() - 1.
اعتبار endIndex في substring(beginIndex, endIndex) مشمولًا؛ الصحيح أنه غير مشمول.
محاولة تعديل String مباشرةً وكأنها تتغير في مكانها؛ عمليات مثل replace و substring تعيد String جديدًا ويجب حفظ النتيجة عند الحاجة.
نسيان أن الكلمات ذات الطول الفردي تحتاج انتباهًا خاصًا عند تقسيمها إلى نصفين ثم محاولة عكس العملية.

قائمة تحقق نهائية قبل الامتحان

أستطيع قراءة عنوان عملية وتحديد: الصلاحية، static، نوع القيمة المُعادة، الاسم، والمعاملات.
أميز بين استدعاء عملية ساكنة واستدعاء عملية على كائن.
أعرف إنشاء كائن باستخدام new والباني (Constructor).
أستطيع استعمال Math.sqrt, Math.abs, Math.min, Math.max, Math.pow, Math.floor و Math.round وفق الـ API.
أستطيع كتابة عملية ساكنة بسيطة مع معاملات و return.
أفهم لماذا نستخدم العمليات لتقليل تكرار الكود.
أستطيع استخراج رقم الآحاد والعشرات باستخدام % و /.
أعرف مجال nextInt(n) وكيف أحوله إلى مجال آخر.
أعرف أن String كائن، وأستطيع استعمال length(), substring(), replace() و charAt().
أعرف أن الفهرس يبدأ من اليسار عند 0، وأن آخر فهرس هو length() - 1.
أستطيع تتبّع كود صغير وتحديد القيمة التي تعيدها العملية أو النص الذي سيُطبع.
أستطيع حل سؤال جديد مشابه لأمثلة الفصل حتى لو تغيّرت الأسماء والقيم.
